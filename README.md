# 自用订阅模板

`config/Myself.ini` 和 `config/Myself_ipv6.ini` 决定节点分组及规则顺序；两份 base YAML 保留各自客户端设置。

## 外置规则集

统一在 `config/rule-providers.yaml` 维护定义，在 INI 的原规则位置通过 `ruleset=策略组,[]RULE-SET,名称` 引用。

- 新增：共享 YAML 加定义，需要的 INI 加引用。
- 修改地址、缓存路径、周期或下载通道：只改共享定义。
- 修改分流目标或优先级：只改 INI 的策略组或位置。
- 停用：删除 INI 引用；所有模板不再引用后，可删除共享定义。
- 重命名：定义和引用一起修改，漏改时生成脚本拒绝发布。

共享文件不是客户端远程 include。VPS 仓库的生成器通过 `rule_providers_url` 读取它，只合并当前 INI 实际引用的项目并校验规则快照；未引用项不下载、不输出。目前支持显式声明完整字段的 classical HTTP YAML/text 规则集，不接受脚本或隐式默认值。

当前只外置 ChinaMax。其下载通道为独立的“规则下载”fallback 组，候选为“全局设置 → DIRECT”。该组在两份 base YAML 中以标准字段定义：每 300 秒探测同一下载站点的小文件，`lazy: false` 保持探测，`expected-status: 200` 不把错误页面当作健康；规则每 86400 秒更新。该通道用于首次下载和后续更新，不改变 ChinaMax 的国内网络分流目标。回退依赖健康检测，不保证某次 HTTP 下载失败立即改走直连重试。更新失败且已有缓存时仍须检查客户端日志；首次没有缓存不能保证可用。
